### About the Experiment 

This experiment helps learners understand how Dynamic Programming solves the Rod Cutting Problem efficiently. Students can explore how maximum revenue is computed for different rod lengths and price tables, visualize DP table construction step-by-step, and compare the optimized approach with brute force intuition.
